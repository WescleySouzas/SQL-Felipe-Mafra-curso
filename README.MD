Este repositório contém minhas anotações, scripts e resoluções de exercícios desenvolvidos durante o **Curso Completo de Banco de Dados e SQL** ministrado pelo instrutor **Felipe Mafra**.

O objetivo é documentar meu aprendizado sobre modelagem de dados, queries avançadas e administração de banco de dados relacional.

## 📚 Tópicos Estudados

Os arquivos estão organizados conforme a progressão das aulas:

- [x] Conceitos de Modelagem de Dados (Entidade, Atributo, Relacionamento)
- [x] Primeira, Segunda e Terceira Forma Normal (1FN, 2FN, 3FN)
- [x] Comandos DDL (CREATE, ALTER, DROP)
- [x] Comandos DML (INSERT, UPDATE, DELETE)
- [x] Consultas Simples e Projeções (SELECT, AS)
- [x] Filtros e Operadores Lógicos (WHERE, AND, OR, LIKE)
- [x] Joins (INNER, LEFT, RIGHT, FULL)
- [x] Funções de Agregação e Agrupamento
- [x] Views e Stored Procedures
